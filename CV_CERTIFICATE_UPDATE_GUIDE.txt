Sandeep Portfolio — CV and Certificate Updates

FILES
- index.html and style.css: portfolio website
- assets/resume.pdf: current CV (the portfolio buttons link to this exact path)
- assets/certificates/: original uploaded certificate PDFs selected for the portfolio

HOW TO UPDATE THE CV LATER
1. Export your new CV as PDF.
2. Rename it to resume.pdf.
3. Replace sandeep_portfoli/assets/resume.pdf with the new file (keep the same path and filename).
4. Commit/push the updated file to the same GitHub repository. The website CV links do not need editing.

HOW TO ADD ANOTHER CERTIFICATE
1. Copy the certificate PDF into assets/certificates/ with a simple filename, e.g. new-course.pdf.
2. Add a new <article class="cert-card"> in the certification grid in index.html, linking to assets/certificates/new-course.pdf.
3. Commit/push the changed files to GitHub.
